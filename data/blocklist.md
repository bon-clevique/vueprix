# vueprix 投稿ブロックリスト

このファイルに ASIN を 1 行 1 件で記載すると、当該商品は投稿対象から除外されます。
記載理由をコメントとして残してください (PR の commit message にも理由を書く)。

## 形式

```
B0XXXXXXXX  # 理由 (例: 配送遅延クレーム多発 / 在庫不安定 / 紹介に向かない商品 など)
```

## ルール

- 1 行 1 ASIN
- `#` 以降はコメント (parser は無視)
- 空行と `#` で始まる行 (見出し) は無視
- ASIN は 10 文字英数字 (`B` で始まることが多い)
