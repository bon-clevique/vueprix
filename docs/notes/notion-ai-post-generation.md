# Notion AI で投稿文を生成する運用ガイド

PR #28 以降、ドラフト作成時の投稿文生成は廃止された。`理由` / `投稿文_X` / `投稿文_Bluesky` の 3 property は **空文字列** で作成され、bon が Notion DB ページ上で Notion AI を使って文言を埋めてから `Status=approved` に遷移させる運用に移行している。

本書は Notion AI の操作手順と、廃止された Claude API のプロンプト要件を再現するための入力テンプレートを記録する。

## 全体フロー

```
GitHub Actions cron (2h)
  ↓ draft 作成 (理由/投稿文_X/投稿文_Bluesky = '')
Notion DB「vueprix 投稿文」 Status=pending_review
  ↓ bon が手動でサクラチェッカー確認
  ↓ Notion AI で 理由 / 投稿文_X / 投稿文_Bluesky を埋める ← 本書の対象
Status=approved
  ↓ Notion automation → Cloudflare Worker → GitHub repository_dispatch
bot-publish.yml が publish.ts を実行
  ↓ payload.reason.trim().length === 0 なら refuse (空ポスト事故防止)
X / Bluesky に投稿
```

publish.ts の reason 空ガード: 空のまま `approved` にすると `buildPostText` が構造的に壊れた投稿を生成するため publish が refuse する。`approved` のまま残るので、後で文言を埋めて Notion automation を再発火させれば再投稿される (`src/publish.ts` の空 reason ガード参照)。

## 操作手順 (Notion DB ページ上)

1. `Status=pending_review` の row を開く
2. 「サクラチェッカーURL」を開いて検証 (規約上 bot 自動化禁止のため手動)
3. ボツなら `Status=rejected` に変更して終了 (publish に流れない)
4. 採用なら以下の順で 3 property を埋める:
   - `理由` (生活シーン文)
   - `投稿文_X`
   - `投稿文_Bluesky`
5. すべて埋めたら `Status=approved` に変更 → automation で publish 発火

## Notion AI プロンプト テンプレート

### 1. `理由` — 生活シーン文 (38 字以内)

Notion AI 「カスタム AI ブロック」または「文章を生成」を起動して以下を入力:

```
あなたは「食・健康・生活の質」をテーマに小さなSNSアカウントで商品を紹介する書き手です。
次の商品について「自分の生活にどう取り入れるか」を1文の日本語で書いてください。

【厳守事項】
- 38字以内 (絶対超えない)
- 体言止めにしない (動詞・助動詞で終わる)
- 値段や割引には触れない (価格は別行で表示する)
- 次の煽り語を使わない: お得 / おすすめ / 必見 / チャンス / 今だけ / 見逃せない / 半額以下 / 必須 / マスト / 神 / 衝撃 / 超 / 激安
- 「〜がお得」「〜がおすすめ」「〜がチャンス」など、商品を主語にした押し売り構文にしない

【書き方】
- 商品の使い方や生活シーンに触れる (朝食 / 仕事中 / 寝る前 / 来客時 / ストック など)
- 一人称や「ふだん」「日々」「いつもの」など、生活への馴染ませ方を示す語があると良い

商品名: <ページの「名前」プロパティの値を貼る>

出力: 1文のみ。前置き・後書き・引用符・絵文字すべて禁止。
```

生成結果が 38 字を超えていたら「もっと短く」と指示してリトライ。

### 2. `投稿文_X` — X 用本文 (280 字以内)

```
以下を組み立てて X の投稿本文を作ってください。280字以内 (絶対超えない)。

【値下がり】<商品名>

<理由 (上で生成したもの)>

通常 ¥<通常価格> → ¥<セール価格> (<割引率>%オフ)

→ Amazonで見る
<Amazon URL>

#Amazon値下がり #生活の質
```

数字 (¥1,000 形式) は「通常価格」「セール価格」プロパティ、`<割引率>` は「割引率」プロパティ (Notion は 0.15 形式で保存しているので 15 と入力)。商品名が長くて 280 字を超える場合は商品名末尾を「…」で切り詰める。

### 3. `投稿文_Bluesky` — Bluesky 用本文 (300 字以内)

X 用と同じテンプレートで上限のみ 300 字。商品名の切り詰め余裕がやや大きい程度の差で、文面は基本的に X と同一でよい。

## トーン調整のヒント

廃止された Claude プロンプトは以下の方針を持っていた (Notion AI への追加指示として再現可能):

- 朝食 / 仕事中 / 寝る前 / 来客時 / ストック などの **生活シーン語** を含めると馴染む
- 「ふだん」「日々」「いつもの」のような **時間軸語** で生活への取り込み感を演出
- 「お得」「おすすめ」「必見」「チャンス」「今だけ」「見逃せない」「半額以下」「必須」「マスト」「神」「衝撃」「超」「激安」は NG ワード
- 商品を主語にした押し売り構文 (「〜がお得」) は避け、ユーザー視点の動詞で結ぶ

## なぜ Claude API を廃止したか

- Notion DB に承認フローがあるため、Notion 上で AI を直接使う方が文体調整・リトライが UI 完結で速い
- 外部 API クレデンシャル (`ANTHROPIC_API_KEY`) と credit 残管理が不要に
- 月 ~$1.2 のコスト削減

詳細は PR #28 と `docs/adr/` 参照。
